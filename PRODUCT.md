# Product

## Register
product

## Users
Slovak competition reviewers grading student submissions together, often reviewing many PDFs in one focused session.

## Product Purpose
Create a project, import original or corrected ZIP archives, annotate PDFs and assign non-negative decimal points. Share projects with reviewers and synchronize durable edits between devices. Export a ZIP compatible with the existing grading software, preserving original PDF filenames and root points.json metadata.

## Brand Personality
Compact, practical, distinctive. A working editor with direct Slovak labels and clear saving feedback. The user prefers the supplied legacy editor reference: dark charcoal canvas, slate panels, vivid cyan tool and selection states, and warm orange grading controls. Preserve personality and density.

## Anti-references
Decorative dashboards, marketing layouts, excessive whitespace, hidden annotation tools and ambiguous save state.

## Design Principles
Keep the document central. Preserve archive fidelity. Make sharing explicit. Keep frequent tools within reach. Surface failures and protect concurrent edits.

## Accessibility & Inclusion
Readable contrast, labeled controls, visible keyboard focus, reduced motion support, responsive panels and keyboard deletion/undo.
